# Paths mathematics game: concept art v1

Four original visual concepts, made with the built-in image generator.
Status: design candidates for discussion; no game code or runtime assets changed.
No screenshots or application captures were taken. Original generated files
remain in their tool-provided locations; the four selected PNGs are copied here.

1. **Living textbook** — a warm editorial contents view with compact chapter
   rows, saved position, question selection and a mathematical preview.
2. **Graph workbench** — a dark solving space with an anchored gold problem,
   teal/violet lines, linked values and compact controls.
3. **Construction challenge** — a light, tactile mathematical stage where
   coefficient controls shape a curve through target points.
4. **Spatial geometry lab** — a dark 3D solid-and-slice activity with a linked
   cross-section, values and the original problem retained above it.

These images explore layout, materials, colour and interaction cues. They are
not validated mathematical diagrams: generated curve placement, axis spacing
and some markers remain approximate, including the workbench after one targeted
correction. Production geometry should continue to come from the checked game
model. Small labels and button dimensions would be tuned during implementation.

The exact generation prompts, correction prompt, original source paths, saved
paths, image dimensions and byte hashes are in `prompts-and-sources.json`.
All four selected images are 1536 x 1024 PNG files.
