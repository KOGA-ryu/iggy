# Parallel subject authoring

Read the [shared contract](../../../docs/PARALLEL_QUESTION_AUTHORING.md).
Also read the AGENTS.md, PILOT.md and fixed sequence.json in your assigned
subject folder. Run commands from /Users/kogaryu/iggy3d/paths as documented.

This directory prepares four subject assignments; files do not authorize their
dispatch. Once explicitly assigned a pilot, complete it directly with no extra
workers. Only the six authoring files listed in the shared contract and your
subject's build output are writable. Other subject folders, shared tools,
instructions, reserved cases, active packages and 3D assets are outside scope.

Use the accepted native textbook format and multiple-choice responses. The
shared contract distinguishes the six exercise roles from the optional written
support levels in older linear/matrix material. Preserve saved-question identities.

Never take screenshots, captures or images; never open a native window or run
font/ImGui probes. Run only the specified pure checks. Keep work uncommitted.
Stop after the assigned pilot's complete candidate and verification receipt;
the coordinator owns integration, builds, publication and the next assignment.
