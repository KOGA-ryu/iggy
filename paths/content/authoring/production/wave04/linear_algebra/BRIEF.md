# Linear algebra: span, independence and basis

Read ../BRIEF.md, ../assignments.json and source hefferon_span_basis in
../SOURCES.json. Only write your assigned source files/authoring folder and
build/production/wave04/linear_algebra/. This brief and registry are coordinator-owned.
Package prod04_linear_span_basis version 1, reading suffix _r,
questions _q01 through _q12. Bind to topic_0090.

Use the registry's explicit Hefferon exercise pool from Two.I.2, Two.II.1 and
Two.III.1. At least six distinct exercises/subparts must seed the 12 questions.
Use real vectors in R2/R3, small integer original entries and exact rational
working. No polynomial/function spaces in this first family. Select finite
bounds for original entries, vector count and coefficient witnesses.

q01-q04 decide span membership and construct coefficients or an inconsistency
witness; q05-q08 establish independence/dependence with a homogeneous system
and actual nonzero dependence relation when appropriate; q09-q12 construct or
verify a basis and coordinates for a vector. At least two mixed problems
select a method. Include a zero vector, a redundant generating vector, an
independent set that does not span the ambient space, and a proper subspace
whose basis need not contain three vectors. Distinguish the subspace from R3.

Define vector, scalar, linear combination, span, independence, dependence,
basis, dimension, coordinates and the matrix formed from COLUMN vectors.
Connect calculations to the definition, not only a rank label. Show row
operations and verify coefficient witnesses against the original vectors.
A basis proof needs both independence and spanning. Coordinate tuples depend
on the stated ordered basis. Identify original pivot columns when selecting a
column-space basis; reduced columns are not generally the same basis vectors.

Use exact rank/nullspace/linear-combination arithmetic derived independently
from originals. Verify every option/reached state and all row operations.
Account for different valid bases and nonzero multiples of a dependence
witness; do not offer two valid alternatives as competing answers. If a local
goal asks for a normalized witness or basis from the original columns, state
that clearly and accurately explain goal-missing alternatives. Reject false
rank, partial-row updates, swapped coordinate order, spanning/independence
confusion and reordered/rescaled-equivalent answers, with valid controls.

Credit Jim Hefferon, Linear Algebra fourth edition, under the author-offered
CC BY-SA 3.0 US option. Exclude externally attributed and question-mark puzzle
exercises. The answer PDF is available for cross-checking; the certificate
