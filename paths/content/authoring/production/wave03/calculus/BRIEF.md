Package prod03_calc_integration version 1; lesson prod03_calc_integration_r;
questions with suffixes _q01 through _q12. Bind all content to topic_0062 /
Integration. Neutral learner titles describe the problem, not its answer.

Use real polynomials of degree at most four, exact rational coefficients and
bounded rational evaluation points. Define the bounds before selecting cases.
q01-q04 find all antiderivatives; q05-q08 solve an initial-value problem
F'=p, F(x0)=y0; q09-q12 calculate definite integrals. Include fractions, negative
coefficients, a reversed pair of limits, cancellation/equal-limit behavior and
a negative signed integral. At least two final-group problems select a valid
method and execute it. Avoid trivial cases that make competing options equal.

Teach integrand, variable of integration, antiderivative, family of functions,
arbitrary real constant, initial condition, endpoints, signed integral and the
Fundamental Theorem. Polynomials are continuous on every real closed interval;
state why the theorem applies. Explain the power rule's exponent restriction;
this wave does not introduce logarithmic, substitution or transcendental
integration. Distinguish signed integral from unsigned area.

Indefinite routes preserve arbitrary C and establish all antiderivatives on
the real interval using the constant-difference fact. F+C and F+5+C describe
the same family and cannot compete as different answers. Initial-value routes
derive C and check both the original derivative and condition. Definite routes
calculate a primitive, both endpoint values and upper minus lower, respecting
the order of the given limits, then independently check the signed value.

Use exact coefficient arithmetic and differentiation to verify every displayed
primitive from the original polynomial. Independently calculate endpoint
values/integrals from original coefficients. Check all reached expressions,
the method's conditions, constant-family equivalence and explicitly requested
forms. Include missing-C, shifted-same-family, wrong-limit-order, false working,
invalid input and goal-form negative controls plus valid alternative controls.
Point samples or numerical quadrature alone are not proof.
