# Prompt 07: Handle Damage and Overlays Without Contaminating the Base

Always execute this prompt. Either build one explicitly requested capability or
prove that damage remains outside the current goal.

## Required reading

- package `WORKSTREAM.md`;
- package `CODED_DEMANDS.md`;
- `workflow/06_damage_and_overlays/AGENTS.md`;
- profile overlay defaults;
- current target-asset semantic attributes.

## Branch A: Damage is outside the goal

Verify:

- intact master remains reproducible;
- fracture, chip, scratch, rust, dirt, soot, damp, polish, blood, wax, and
  other optional lanes default to zero unless the current intact material
  physically requires a layer such as forge scale;
- final proofs do not contain accidental damage;
- profile, manifest, shader defaults, and tests agree;
- README and dossier name the excluded capabilities.

Set Stage 07 to `skipped-out-of-scope` with evidence. A skip is not permission
to ignore accidental damage-like marks.

## Branch B: One damage or overlay capability is in the goal

Define:

- exact damage type;
- material response;
- physical cause;
- eligible location;
- direction or exposure;
- size, depth, density, and age;
- geometry, signed height, decal, or shader ownership;
- typed color, roughness, AO, metalness, and mask effects;
- exclusion zones;
- default-off behavior.

Author a finite motif library with several visibly distinct examples and quiet
variants. Use declared mirrors, scales, rotations, shears, or clipping only
when they preserve physical logic.

For sculpted stone chipping, keep separate compact-tap, short-drag,
subtractive-pock, additive-aggregate, and flattened-rest families when those
events are supported. Large loss belongs primarily to exposed arrises,
corners, joints, ends, or explicit impacts; protected face centres default
quiet.

Apply only reviewed `DMG` coded demands. If damage is outside scope, the coded
blueprint must still contain the default-off validation and test code.

Build placement from explicit semantics:

- end distance;
- edge or arris class;
- contact or traffic;
- load or bearing;
- fastener or joint;
- doorway, table, hallway, floor, or stair identity;
- gravity, weather, heat, or soot source;
- fracture interior versus outer face.

Do not place marks with equal random probability across the asset.

## Required damage proof

Show:

- intact beside damaged;
- eligible placement visualization;
- at least four distinct motifs;
- isolated geometry or height;
- isolated color and roughness;
- close, grazing, gameplay, and actual-asset views;
- wrong-location negative test;
- default-off base material.

## Dossier update

Record:

- branch selected;
- intact master path;
- damage or overlay contract;
- pattern and placement owners;
- tests and proof paths;
- excluded damage families.

## Exit gate

Do not advance unless:

- excluded damage is proven off, or one included capability is causal,
  contextual, optional, and proven;
- eligible and protected semantics match `damage_placement`;
- intact source remains unchanged;
- no generic grime or random placement entered the champion.

Then execute `08_adversarial_proof.md`.
